## 2024-11-06 - Memory instructions: Replace expensive string manipulations with ClassValue cache
**Learning:** `javaClass.simpleName.lowercase()` is being called repeatedly during PSI tree traversals (e.g., in `OptimizedSymbolSearch.kt`, `FindClassTool.kt`, `GetSignatureTool.kt`). This causes frequent string allocations and CPU overhead, especially when processing many elements. This was explicitly requested as a required optimization in memory: "Use `ClassValue<T>` to cache expensive per-class computations (such as reflection or string manipulations like `simpleName.lowercase()`) during frequent operations like PSI tree traversals to prevent excessive allocations and CPU overhead."
**Action:** Created `ClassNameCache.kt` leveraging `ClassValue` to cache these strings per-class. Will apply it where it's heavily used.
